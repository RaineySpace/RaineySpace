# 👋 你好，朋友

**微羽助手**是一款简洁、高效、智能的新媒体运营辅助工具，为您提供多账号管理、文章编辑、导入文章、文章同步、批量发布等多样化服务。

## 🎯  我们的初心
在过往运营个人公众号的历程中，我深度接触并使用了市面上琳琅满目的公众号工具。然而，在实际操作过程中，这些工具暴露出诸多令人难以接受的痛点。纵观当下的公众号工具市场，各类问题层出不穷。以插件类型的工具为例，当用户需要在浏览器上进行账号切换登录时，其操作流程极为繁琐复杂。每一次切换，都需要用户依次完成多个步骤，诸如输入账号、密码，进行身份验证等，这无疑极大地增加了用户的时间成本，降低了工作效率。

部分工具在定价策略上存在严重问题，价格设定过高，远远超出了其实际价值，导致性价比严重失衡。对于许多运营者，尤其是个人运营者或小型团队而言，这无疑带来了沉重的经济负担，使得他们在选择工具时不得不望而却步。

还有一些工具的用户界面（UI）设计陈旧落后，风格刻板老套，仿佛还停留在上个世纪的审美水平。这种过时的设计不仅在视觉上无法给用户带来愉悦感，更在操作交互上存在诸多不便，极大地影响了用户的操作体验，降低了用户使用工具的积极性。

更糟糕的是，有部分工具由于长期缺乏维护更新，已经无法正常使用，连最基本的功能需求都无法满足，这对于依赖工具进行公众号运营的用户来说，无疑是一场灾难。

基于以上种种痛点，我萌生了自主开发一款工具的想法。在广泛收集了众多运营者的实际需求之后，决定全力打造一款简洁、高效、智能的新媒体运营辅助工具 —— 微羽助手。旨在帮助每一位从事运营工作的朋友从繁琐的基础操作中解放双手，将更多的精力集中投入到更具创造性和价值的内容创作与运营策略制定等工作中。

## 💻 支持的操作系统

我们目前研发资源有限，也受限于技术框架，目前支持的操作系统如下：

### Windows

支持 **Win10 以及更高版本**

> 因 [Chrome 团队已停止对 Windows 7/8/8.1 系统的支持](https://support.google.com/chrome/thread/185534985/sunsetting-support-for-windows-7-8-8-1-in-early-2023?hl=en)，我们很遗憾无法支持这些系统版本

### MacOS

对 macOS 仅提供 64 位版本，支持 **macOS 10.11 (El Capitan) 以及更高版本**。

我们也同时支持**Apple Silicon (arm64)**设备
