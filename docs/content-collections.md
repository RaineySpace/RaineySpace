# 内容与摄影维护

所有类型存放在 `public/<slug>/index.md`，完整属性、类型含义、集合布局和跳转规则见 [文档即实体](./entities.md)。目录名是 slug，详情 `/slug/`，公开 Markdown `/slug.md`；源文件继续使用同目录相对资源。

## 文章

```yaml
---
type: article
title: 文章标题
date: 2026-10-07
summary: 简短摘要
tags: [人间]
---
```

公开文章必须有 title、date、summary；tags、keywords 可选。`hidden: true` 排除文章列表、标签统计和订阅，但不排除索引、关联或摄影。关于、授权、测试页使用隐藏文章，日期可以省略。`noindex` 控制索引，`showHeader` 控制自动头部，三个选项互不替代。

cover 可选，用于详情头部、分享和悬浮卡片；不在文章列表显示，不从正文自动取首图。没有 cover 时分享使用站点默认图，悬浮卡片回退到 icon 或标题首字。RSS/Atom 严格按文章日期倒序，不使用 pinned。

## 文章筛选

`/article/` 默认展示全部公开文章。标签为单选，再次点击取消；默认一行，可展开或收起，数量按公开文章统计，一篇重复标签只计一次。标签按数量降序、同数量按中文名称排序。`?tag=诗笺` 支持分享、刷新和前进后退，未知或空标签当作未筛选。筛选不改变置顶和日期顺序。keywords 不参与筛选或统计。

### 标签命名与归类

文章优先沿用以下标签，保持简短、有文学意味，也能辨认内容方向：

| 标签 | 内容方向 |
|---|---|
| 年鉴 | 年度回顾与生活切片 |
| 诗笺 | 诗歌与诗性短句 |
| 人间 | 家人、朋友、青春、日常经历与个人感触 |
| 生涯 | 职业成长、工作方式、离职与重新出发 |
| 造物 | 产品体验、设计取舍与把想法做出来的过程 |
| 行旅 | 旅行经历、沿途见闻与归来 |
| 游牧 | 带着工作迁移，自主安排时间与地点的生活方式 |
| 虚构 | 小说与想象中的人物、故事 |

`tags` 仍为可选字段。归类时按正文主线通常选择一个标签，明确跨主题时保留两个。例如《这一次，我们没有再等》使用 `人间、行旅`，《我没有下班时间，但我更自由了》使用 `生涯、游牧`。不因正文提及某个话题就追加标签；年鉴与诗笺通常保留各自标签即可。


旧图集保留原来的摄影、行旅、杭州等 tags 与地点文字；hidden 使其不参与文章标签统计。关于、授权、测试页无需文章标签。

## 摄影图片

```md
![海边等候日落的人](./sunset.jpg "photography")
```

标准图片 title 精确为 `photography` 才进入摄影集合；普通图片、HTML img、封面、icon 不自动收录。页面不显示该标记为 tooltip，其他图片 title 正常显示。

标记图片必须在当前文档目录内，使用相对路径、文件存在且 alt 非空，否则校验失败。引用式 Markdown 图片也支持 title 标记。同文档同路径去重，只要一次标记便收录；不同文档不按文件内容去重。

摄影页直接平铺全部图片，移动端 2 列、较宽屏幕 3 列，缩略图 4:5、懒加载，共用一个灯箱序列。排序优先 EXIF 拍摄时间，缺失时用来源日期、再按来源 slug 与正文顺序；没有日期排最后，不把来源日期冒充拍摄时间。location 只是来源文档的地点说明，不从 GPS 自动推断城市。

首页从同一序列取前 6 张并保留照片条动效。灯箱“查看出处”链接到文档的稳定图片锚点。图片优化、EXIF、原图与同名 `.mov` / `.MOV` Live Photo 保持原有能力；普通未标记插图仍有灯箱能力。

图集仍是普通 article。旧图集保留 hidden，删除文档级 photography 和 cover，并给正文图片添加标记；删除 cover 属性不代表删除图片文件，不增加 showCover。

## 项目、朋友与联系方式

每个条目新建自己的 Markdown 文档，只需要 metadata，正文可空。项目／朋友如希望访问详情时跳转，明确设置 `url` 与 `redirect: true`；联系方式默认保留详情并提供用户点击的联系入口。日期可以省略，不编造项目开始或收录时间。

引用采用普通内链，独立段落会展开卡片或集合：

```md
最近在做 [小分身](/xiaofenshen/)。

[项目](/project/)

[朋友](/friend/)

[联系方式](/contact/)
```

新旧集合路径与系统端点均为保留 slug，创建脚本和内容校验器使用同一名单。不要添加 JSON 名录或旧的链接 title 标记。
